# Denver v2.0.0 — Federation Foundations (DRAFT — do not publish)

**Status:** DRAFT release notes for the `v2.0.0` tag. Finalize and publish only after a successful
`v2.0.0-rc1` staging validation and the `main` fast-forward (see `FEDERATION_RELEASE_POLICY.md`).

## Overview
Establishes the **Ava EPC Federation v2.0** foundations in Denver: Denver is the Enterprise EPC Delivery
Platform that owns the EPC business workflow and delegates technical execution to specialist engines
(Menlo, Crania, Ava Math, Ava-ControlCore). All federation runtime capability is **additive and
flag-gated (default OFF)** — this release changes **no runtime behavior** until a flag is enabled.

## What's included
**Federation primitives (dormant, flag-off):**
- Denver↔Menlo canonical event edge adapter + commissioning status mirror + gateway (R1)
- AI Capability Registry (R2)
- Universal event publisher / canonical vocabulary (R3)
- Universal Object Registry identity + reference rules (R4)
- Knowledge Graph + Digital Thread traversal (R5)
- Idempotency middleware, OpenAPI publication, first-class Denver MCP server (R6a/b/c)
- EAP document-authority client (R7)
- Plus the prior commissioning-extraction work (boundary scaffolding, epcCore split, portable export bundle)

**Architecture, governance & docs:**
- `REFERENCE_ARCHITECTURE.md` (master front door), `ECOSYSTEM_INTEGRATION_CONTRACT.md` v2.0
- Governance: change policy, RFC template, adoption guide, compliance checklist, lifecycle, release policy
- 10 ADRs (`docs/adr/`)

## Breaking changes
**None at runtime.** All federation surfaces are off by default; existing routes/behavior are unchanged.

Adds `070`–`081` (RLS hardening, pgvector, SAML/SCIM, pay applications, coordination, safety, NCR/CAPA,

## Known limitations
- Universal Object Service, Knowledge Graph, and idempotency store are **in-memory reference
  implementations** — durable backends are required before enabling those flags in production.
- `AI_GOVERNANCE.md` / `DATA_GOVERNANCE.md` / `SECURITY_ARCHITECTURE.md` are planned extractions (content
  currently in `ECOSYSTEM_INTEGRATION_CONTRACT.md` §11/§3/§9 + `ENTERPRISE_SECURITY_SPEC.md`).

## Deferred implementation (post-release, flag-gated)
- Persist UOS/graph; capability health + version negotiation; event `spec_version` on the wire; AI-artifact
  envelope; mount idempotency middleware (after tenant resolution) + Denver MCP server (with s2s auth);
  expand OpenAPI coverage; Menlo bootstrap ingest. (See contract follow-up checklist.)

## Rollback
- **Git:** promotion is a fast-forward of `main` to the federation lineage. Rollback = reset `main` to the
  pre-promotion anchor (recorded at promotion time); no history rewrite of the federation branch.
- **Database:** migrations are forward-only — roll back via the pre-migration snapshot / PITR.
- **Features:** all flags ship OFF; if an enabled flag misbehaves, flip it off (no code redeploy needed)
  before any git/DB rollback.
