# Architecture Decision Records (ADRs)

Permanent record of the federation's foundational architectural decisions — so the *why* outlives any
single implementation and the federation can evolve without tribal knowledge.

- **Format:** each ADR captures Context, Decision, Consequences, and Alternatives considered.
- **Status values:** Proposed → Accepted → Superseded (by ADR-NNN) / Deprecated.
- **Changing a decision:** open an RFC (`../../FEDERATION_RFC_TEMPLATE.md`); an accepted RFC may add a new
  ADR that supersedes an existing one. ADRs are immutable once Accepted — supersede, don't rewrite.
- **Source of truth for the contracts themselves:** `../../ECOSYSTEM_INTEGRATION_CONTRACT.md`.
