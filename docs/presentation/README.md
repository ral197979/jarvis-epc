## What this platform is (in one line)

> The AI-powered command center for **delivering and commissioning complex capital projects** — one auditable system of record that proves a facility is ready to operate.

## A note on honesty

This package is written to be sold from **and** to survive a technical evaluation. It leads with the platform's genuine strengths (full project lifecycle, deep commissioning, financial controls, grounded document AI, predictive and portfolio intelligence) and is explicit about scope boundaries (it is not a real-time SCADA/plant-operations system, not a full EAM/CMMS, and its discipline design calculators are drafting aids — see `COMPETITIVE_POSITIONING.md`). That candor is deliberate: it's what wins enterprise trust.
