# Product Screen Index

> Inventory of every customer-facing screen in the application. For each: **Screen · Purpose · User Type · Key Actions · Business Value**.
>
> Screens are grouped by the nine work domains. Labels match what users see in the navigation. (The platform ships a classic UI and a next-generation "Mission Control" UI over the same business logic; screen purposes are identical across both.)

---

## Operations

| Screen | Purpose | User Type | Key Actions | Business Value |
|---|---|---|---|---|
| **Dashboard** | At-a-glance portfolio health on login | All roles | View KPI tiles, EVM gauges, activity feed; drill into any tile | Shared, trustworthy starting picture; faster decisions |
| **Projects** | Master project register | PM, ops | Create/edit projects; set status; filter by project | One authoritative project record |
| **Actions** | Cross-module action / work system | All roles | Create, assign, escalate, close actions; track SLA | Nothing falls through the cracks |
| **Timesheets** | Workforce time capture & approval | Supervisors, payroll | Enter weekly hours; approve; allocate to cost codes | Accurate labor cost & payroll |
| **Team** | Roster & assignments | Resource mgrs, PM | Manage roster, roles, rates; assign to projects | Better utilization & costing |
| **Notifications** | Real-time alert center | All roles | View, mark read; set preferences | Timely response; less email reliance |

## Scope note

Two requested "screens" do **not** exist as real-time operational surfaces and are intentionally out of scope: a **real-time SCADA/plant-operations console** (the platform commissions control systems and monitors sensors, but does not operate a running plant) and a **dedicated CMMS work-order/inventory module** (the Action Center covers task management; parts/inventory is handled via integration). See `COMPETITIVE_POSITIONING.md` and the scope notes in `CUSTOMER_FEATURE_CATALOG.md`.
