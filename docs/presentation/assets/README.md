# Presentation Assets

Diagrams, workflow descriptions, and slide-graphic specifications for the Denver Engineering customer presentation package.

## Contents

| File | Purpose |
|---|---|
| `DIAGRAMS.md` | Renderable diagrams (Mermaid) for the lifecycle, commissioning workflow, readiness model, domain map, intelligence layer, competitive seam, and key workflows. Drop into any Mermaid-capable renderer or convert to slide graphics. |
| `SLIDE_GRAPHICS_SPEC.md` | A build spec for every "Suggested graphic" in `PRESENTATION_SLIDES.md` — what to show, the data, layout, and the visual style. |
| `BRAND_AND_STYLE.md` | Visual language, color, and typography guidance so all collateral looks consistent. |

## How to use

- **Design team:** start with `SLIDE_GRAPHICS_SPEC.md` (paired slide-by-slide with the deck) and `BRAND_AND_STYLE.md`.
- **Quick render:** paste any block from `DIAGRAMS.md` into a Mermaid live editor or a Markdown previewer that supports Mermaid to get an instant diagram.
- **Source of truth:** every diagram reflects capabilities documented in the presentation package, which in turn reflect the live application.
