# Brand & Style Guidance

> Visual language for all Denver Engineering customer collateral, so the deck, one-pagers, and diagrams look like one product.

## Design language

**"Industrial Precision."** Confident, engineered, and calm. The look should feel like mission-control software for serious infrastructure — not a consumer SaaS landing page. Lots of structure, clean grids, precise alignment, generous whitespace.

## Color

| Role | Suggested | Use |
|---|---|---|
| Base (dark) | Near-black / deep slate | Hero and section dividers |
| Surface (light) | Off-white / light gray | Content slides |
| Primary accent | A single strong engineered hue (e.g., a precise blue or teal) | Emphasis, key data, one element per slide |
| Status — good | Green | Ready / healthy / on-track |
| Status — caution | Amber | At-risk / watchlist |
| Status — alert | Red | Not-ready / breach / overrun |
| Neutral ink | Dark gray | Body text |

Rule: **one accent per slide.** Status colors are reserved for status (readiness, heatmaps, EVM health) — don't use red/amber/green decoratively.

## Typography

- **Headings:** a precise geometric or grotesk sans (e.g., the Material Symbols-adjacent families used in the next-gen UI). Tight, confident.
- **Body:** a highly legible sans at comfortable size — readable from the back of a room.
- **Data/labels:** a monospaced or tabular-figure face for numbers so columns align.
- Hierarchy: one big idea per slide; one headline; minimal body.

## Iconography

- Line icons, consistent weight, engineered feel. Material Symbols / Lucide families pair well with the next-gen UI.
- Each work domain gets a consistent icon reused across all collateral.

## Data visualization

- Gauges for scores (readiness, health, CPI/SPI). Bars for comparisons. Lines for trends (S-curves, forecasts). Heatmaps for portfolio risk.
- Always label axes and units. Never show a number without its meaning.
- Forecasts must show a confidence cue (the platform exposes a goodness-of-fit signal) — depict uncertainty honestly.

## Voice & tone

- **Confident, specific, honest.** Lead with outcomes, prove with capability, quantify with ROI.
- Prefer concrete nouns and numbers over adjectives. "Readiness score with five weighted components" beats "powerful analytics."
- **Never overstate scope.** Don't depict real-time SCADA/plant operations or certified discipline calculators. Honest scope is part of the brand's credibility.

## Consistency checklist (every asset)

- [ ] One idea, one headline, one accent
- [ ] Status colors used only for status
- [ ] Numbers consistent with `ROI_ANALYSIS.md`
- [ ] No capability claim beyond the live application
- [ ] Domain icons consistent with the rest of the deck
- [ ] Legible from the back of the room
