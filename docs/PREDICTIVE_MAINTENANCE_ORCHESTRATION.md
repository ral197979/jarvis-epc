# Predictive Maintenance Orchestration

**Denver Engineering — Ava Phase 6 (v6.0.0)**

## Overview

The Maintenance Forecast Engine predicts equipment health degradation, generates maintenance recommendations, and schedules optimal maintenance windows — all before failures occur.

## Asset Health Score

The `AssetHealthScore` is a composite 0–100 score weighted across five dimensions:

| Component | Weight | Source |
|-----------|--------|--------|
| Inspection completion | 30% | `inspections` table |
| Deficiency severity | 25% | `deficiencies` table |
| Incident history | 20% | `realtime_event_log` |
| Asset age | 15% | Static baseline (extensible) |
| Utilization | 10% | Static baseline (extensible) |

### Inspection Score
```
score = completion_rate × 100 − recency_penalty
recency_penalty = min(30, days_since_last_inspection / 12)
```
Assets not inspected for >1 year lose up to 30 points.

### Deficiency Score
```
deductions = critical_open × 20 + high_open × 10 + other_open × 3
score = max(0, 100 − deductions)
```

### Incident Score
```
incidents_90d = count from realtime_event_log (equipment_failure, maintenance_required, sla_breached)
score = max(0, 100 − incidents × 15)
```

## Maintenance Recommendations

Generated by scanning at-risk equipment twins:
```
predictedFailureRisk = riskScore × 0.6 + (100 − healthScore) × 0.4
```

| Predicted Failure Risk | Priority |
|----------------------|---------|
| ≥ 80 | immediate |
| 60–79 | high |
| 40–59 | medium |
| < 40 | low |

**Maintenance type:**
- `healthScore < 50` → corrective (fix now)
- Otherwise → preventive (scheduled maintenance)

**Window calculation:**
- `immediate`: starts now, ends +7 days
- Others: starts +7 days from now, ends +14 days

**Duration estimate:**
- Failure risk ≥ 60%: 4–8 hours
- Otherwise: 1–2 hours

## Trend Analysis

Health trend is derived by comparing the new overall score against the stored `health_score`:
- Delta > +5: `improving`
- Delta < −5: `degrading`
- Within ±5: `stable`

## API Endpoints

```
GET /api/v1/portfolio/maintenance/recommendations?entityType=equipment
GET /api/v1/portfolio/maintenance/health/:twinId
```

## Integration

The `SchedulingAgent` (Phase 5) reads maintenance recommendations and schedules the work items. The `ValidationAgent` verifies completion evidence against the maintenance record. The `AssetHealthPanel` frontend component displays the composite score with breakdown gauges.
